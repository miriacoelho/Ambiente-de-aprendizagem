🚀 O comando ALTER TABLE

Nesta aula, vamos aprender como modificar estruturas já existentes em um banco de dados utilizando o comando ALTER TABLE. Você verá como adicionar, remover e alterar colunas, além de trabalhar com restrições como chave primária e chave estrangeira.

💡 Você vai compreender que:
🔹 ALTER TABLE modifica tabelas existentes
🔹 ADD adiciona colunas e restrições
🔹 CHANGE altera nomes e tipos de colunas
🔹 MODIFY modifica tipos de dados
🔹 DROP remove colunas e chaves
🔹 RENAME altera o nome de tabelas
