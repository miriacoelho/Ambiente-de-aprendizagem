🚀 Introdução à SQL e Estrutura de Bancos de Dados

Nesta aula, você aprenderá os fundamentos da linguagem SQL, entendendo como criar bancos de dados, definir tabelas e escolher corretamente os tipos de dados para armazenar informações.

💡 Você vai compreender que:
🔹 SQL é a linguagem padrão dos bancos relacionais
🔹 DDL cria estruturas e DML manipula dados
🔹 CREATE DATABASE cria bancos de dados
🔹 CREATE TABLE define tabelas e atributos
🔹 Os tipos de dados impactam armazenamento e precisão
