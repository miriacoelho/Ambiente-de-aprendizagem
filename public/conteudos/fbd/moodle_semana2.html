🚀 Conceitos de Banco de Dados

Iniciamos esta semana dando os primeiros passos na compreensão dos fundamentos de Banco de Dados — conceitos que serão a base para toda a disciplina.

Antes de trabalhar com comandos, consultas e modelagem, é essencial entender claramente:

  • O que é um Banco de Dados
  • A diferença entre dado e informação
  • A importância dos BD no dia a dia
  • Noções iniciais de modelos de dados

🧠 Como estudar nesta semana

Nesta semana, o objetivo é compreender os conceitos-base de Banco de Dados (o que é BD, diferença entre dado e informação e uma visão inicial de modelos de dados) e fixar o conteúdo por meio de exemplos simples.

📘 1º Passo – Acesse o material da semana

Leia o PDF “Introdução a Banco de Dados” com foco em:

✔ Conceito de Banco de Dados
✔ Diferença entre dado × informação
✔ Por que Banco de Dados é importante
✔ Noções iniciais de modelos de dados
📝 2º Passo – Registre os conceitos (do seu jeito, mas com método)

Faça um mini-resumo contendo:

Definição + 1 exemplo para cada item:

  • Dado – Ex.: “23”, “MG”, “Aprovado”
  • Informação – Ex.: “23 alunos responderam o quiz”
  • Banco de Dados – Ex.: “Sistema da escola guardando notas e matrículas”
  • Modelo de dados – Ex.: “Forma como organizo entidades e relacionamentos”
🎯 3º Passo – Prática rápida (fixação)

Responda ao quiz da semana.

Ao finalizar, revise os itens que você errou e reescreva a definição correta em 1 frase objetiva.

💡 Dica: estudar não é apenas ler — é organizar, resumir e praticar o que você aprendeu.
