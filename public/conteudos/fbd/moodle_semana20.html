🚀 Revisão para a Prova Final de Banco de Dados

Nesta semana faremos uma revisão dos principais conteúdos que serão cobrados na prova. O objetivo é retomar os conceitos fundamentais do modelo relacional e da linguagem SQL, relacionando teoria, comandos, tipos de dados, restrições e manipulação de registros.

💡 Você deve saber:
🔹 Como um banco de dados relacional é organizado em tabelas, atributos, tuplas e domínios
🔹 O papel das chaves primária, alternativa e estrangeira
🔹 O que é integridade referencial e por que ela protege a consistência dos dados
🔹 Diferença entre SQL, DDL e DML
🔹 Como usar CREATE, DROP, ALTER, INSERT, UPDATE e DELETE
🔹 Como aplicar tipos de dados e restrições de integridade em tabelas SQL

📚 Conteúdo da Revisão

📌 Composição de um banco de dados relacional
📌 Relações, tabelas, atributos, tuplas e domínios
📌 Propriedades das relações
📌 Chaves: primária, alternativa e estrangeira
📌 Integridade referencial
📌 SQL, DDL e DML
📌 CREATE DATABASE, CREATE TABLE e DROP TABLE
📌 Tipos de dados numéricos, caracteres e temporais
📌 Restrições NOT NULL, DEFAULT, PRIMARY KEY, UNIQUE, CHECK e FOREIGN KEY
📌 ALTER TABLE: ADD, ALTER, MODIFY, CHANGE, DROP e RENAME
📌 INSERT: sintaxe básica, uso de colunas explícitas, inserção de uma tupla e inserção de múltiplas tuplas
📌 INSERT com integridade referencial: cuidado ao inserir registros em tabelas que possuem chave estrangeira
📌 UPDATE: alteração de um campo, alteração de vários campos e atualização de múltiplos registros
📌 UPDATE com WHERE: como definir exatamente quais registros serão modificados
📌 DELETE: remoção de registros de uma tabela usando condições
📌 DELETE com operadores: uso de =, >, <, BETWEEN, IN e outras condições
📌 Cuidados com UPDATE e DELETE sem WHERE, proteção do MySQL e integridade dos dados
🔄 Comandos DML que também fazem parte da revisão:
INSERT — inclui novos registros em uma tabela. Exemplo: INSERT INTO peca VALUES (...);
UPDATE — altera valores de registros existentes. Exemplo: UPDATE peca SET preco = 2.50 WHERE num_peca = 1;
DELETE — remove registros de uma tabela. Exemplo: DELETE FROM peca WHERE num_peca = 1;
Atenção especial ao uso da cláusula WHERE, pois ela define quais registros serão alterados ou excluídos.

🧠 Como estudar para a prova

  • Revise os conceitos do modelo relacional: tabela, relação, atributo, tupla, domínio e chave.
  • Observe a diferença entre comandos de definição da estrutura, como CREATE, ALTER e DROP, e comandos de manipulação dos dados, como INSERT, UPDATE e DELETE.
  • Pratique a leitura de comandos SQL e tente identificar o que cada parte da sintaxe realiza.
  • Compare as restrições de integridade e entenda em que situação cada uma deve ser usada.
  • Dê atenção especial ao uso de chaves primárias e estrangeiras, pois elas são essenciais para manter a integridade referencial.
  • No INSERT, confira a ordem das colunas, os tipos de dados e se as chaves estrangeiras já existem nas tabelas referenciadas.
  • No UPDATE, identifique quais campos serão alterados no SET e quais registros serão filtrados pelo WHERE.
  • No DELETE, verifique sempre a cláusula WHERE para evitar exclusões indevidas e observe possíveis restrições de chave estrangeira.
💡 Pergunta guia: “Ao ler um comando SQL, consigo explicar qual estrutura ou quais registros serão afetados?”
