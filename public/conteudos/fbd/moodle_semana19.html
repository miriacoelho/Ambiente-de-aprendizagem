🧠 Como estudar nesta semana

  • Revise o esquema do banco de dados Fornecedor e identifique a função de cada tabela.
  • Compare os comandos INSERT, DELETE e UPDATE, observando a finalidade de cada um.
  • Pratique comandos INSERT com todos os valores, com colunas explícitas e com múltiplas tuplas.
  • Observe as regras para textos, datas, números inteiros, números decimais e valores NULL.
  • Analise exemplos em que o SGBD rejeita operações por violação de chave estrangeira ou chave primária.
  • Treine comandos DELETE com WHERE, AND, OR, IS NULL, IS NOT NULL e operadores de comparação.
  • Estude UPDATE usando SET para definir novos valores e WHERE para limitar quais registros serão alterados.
  • Antes de executar DELETE ou UPDATE, pense: quais registros serão afetados?

🌟 Resumo da Semana

INSERT
Adiciona novas tuplas a uma tabela existente. Os valores devem respeitar a ordem das colunas ou a lista de colunas informada. Chaves primárias não aceitam NULL e chaves estrangeiras devem referenciar registros existentes.
DELETE
Remove registros de uma tabela. A cláusula WHERE define quais tuplas serão excluídas. Sem WHERE, todos os registros da tabela são removidos, mas a estrutura da tabela permanece no banco de dados.
UPDATE
Modifica valores em registros existentes. A cláusula SET indica os novos valores, e a cláusula WHERE limita quais registros serão alterados. Sem WHERE, todos os registros da tabela podem ser atualizados.
✅ Dica final: antes de executar DELETE ou UPDATE, teste a condição com SELECT para verificar quais registros serão afetados.

🎯 Encerramento

Os comandos INSERT, DELETE e UPDATE são fundamentais para manipular dados em bancos de dados relacionais. Eles devem ser utilizados com atenção, pois alteram diretamente o conteúdo armazenado nas tabelas.

Ao estudar, procure sempre identificar a tabela envolvida, os campos utilizados, as condições aplicadas e o impacto da operação sobre os registros.
