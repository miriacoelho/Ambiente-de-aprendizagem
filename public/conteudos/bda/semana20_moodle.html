📝 Revisão para a Prova Final

Nesta revisão, vamos retomar os principais conteúdos que serão cobrados na prova final, com foco na construção de consultas SQL, combinação de dados entre tabelas, geração de resultados resumidos, controle de segurança e criação de recursos programáveis no banco de dados, como triggers, funções e procedures.

💡 Você deverá compreender que:

🔹 A junção interna retorna apenas os registros correspondentes entre tabelas
🔹 A junção externa permite exibir registros mesmo quando não há correspondência
🔹 As funções de agregação resumem dados por meio de cálculos
🔹 A segurança em banco de dados controla usuários, acessos e permissões
🔹 Triggers são executadas automaticamente diante de eventos no banco
🔹 Functions retornam valores e podem ser reutilizadas em consultas
🔹 Procedures organizam comandos SQL para execução de rotinas no banco

🧠 Como estudar para a prova final

  • Revise a diferença entre INNER JOIN, LEFT JOIN e RIGHT JOIN.
  • Pratique consultas envolvendo duas ou mais tabelas.
  • Observe quais campos fazem a relação entre as tabelas.
  • Resolva exercícios usando COUNT, SUM, AVG, MIN e MAX.
  • Treine o uso de GROUP BY e HAVING em consultas com agrupamento.
  • Revise comandos de segurança, especialmente CREATE USER, GRANT e REVOKE.
  • Estude a estrutura de criação de triggers e o uso de BEFORE, AFTER, NEW e OLD.
  • Compare funções e procedures, observando quando cada uma deve ser utilizada.
  • Pratique a leitura dos enunciados para identificar qual recurso SQL deve ser aplicado.
💡 Pergunta guia: “Como consultar, resumir, proteger e automatizar operações em um banco de dados?”

🧩 Atividade de revisão

Resolva exercícios práticos envolvendo consultas com INNER JOIN, LEFT JOIN, RIGHT JOIN, funções de agregação, comandos de segurança, triggers, functions e procedures. Dê atenção especial à interpretação dos enunciados e à escolha correta dos comandos SQL.

🧠 Sugestões de prática:

1. Criar uma consulta com INNER JOIN entre duas tabelas relacionadas.
2. Criar uma consulta com LEFT JOIN mostrando registros sem correspondência.
3. Usar COUNT, SUM, AVG, MIN e MAX em consultas SQL.
4. Agrupar resultados com GROUP BY e filtrar grupos com HAVING.
5. Criar um usuário e conceder permissões com GRANT.
6. Revogar permissões usando REVOKE.
7. Criar uma trigger para executar uma ação automaticamente.
8. Criar uma função para retornar um valor calculado.
9. Criar uma procedure e executá-la com o comando CALL.

🎯 Encerramento

Para a prova final, é importante compreender não apenas a sintaxe dos comandos, mas também a finalidade de cada recurso estudado. As junções permitem combinar dados de diferentes tabelas; as funções de agregação ajudam a resumir informações; os comandos de segurança controlam o acesso aos dados; e triggers, funções e procedures permitem automatizar e organizar rotinas dentro do banco de dados.

Revise os exemplos, pratique os comandos no MySQL e procure entender o resultado gerado por cada consulta ou rotina. Isso ajudará na resolução das questões práticas e na interpretação dos problemas apresentados na avaliação.
