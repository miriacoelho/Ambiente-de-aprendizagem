💻 Prática Guiada em SQL – INNER JOIN

Nesta atividade prática, você irá aprender como utilizar INNER JOIN no banco de dados EMPRESA.

📘 Passo 1 – Baixe e execute o script do banco de dados Empresa

Execute o script do link abaixo no mysql:

🔎 Script banco de dadados Empresa

📘 Passo 2 – Execute o produto cartesiano

Execute a consulta abaixo:

SELECT *
FROM funcionario, departamento;

🔎 Observe: o número de linhas será muito grande.

🔍 Passo 3 – Filtrando com WHERE 
SELECT *
FROM funcionario f, departamento d
WHERE f.dnr = d.dnumero;

💡 Agora os dados começam a fazer sentido.

🔗 Passo 4 – Usando INNER JOIN 
SELECT *
FROM funcionario f
INNER JOIN departamento d
ON f.dnr = d.dnumero;

✅ Mesmo resultado, porém com sintaxe mais clara e recomendada.

📊 Passo 5 – Selecionando colunas específicas 
SELECT f.pnome, d.dnome
FROM funcionario f
INNER JOIN departamento d
ON f.dnr = d.dnumero;
👨‍👩‍👧 Passo 6 – Novo JOIN (dependentes) 
SELECT f.pnome, d.nome_dependente
FROM funcionario f
INNER JOIN dependente d
ON f.cpf = d.fcpf;
🎯 Desafio Final

Crie uma consulta que retorne:

  • Nome do funcionário
  • Nome do departamento
  • Nome do dependente

💡 Você precisará usar 2 INNER JOIN.
