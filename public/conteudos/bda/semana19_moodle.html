⚙️ Rotinas e Gatilhos em Banco de Dados

Nesta aula estudaremos recursos importantes para automatizar ações e organizar regras de negócio diretamente no banco de dados: functions, stored procedures e triggers.

💡 Você vai compreender que:

🔹 Functions e procedures são rotinas armazenadas no banco
🔹 Functions sempre retornam valores
🔹 Procedures executam comandos e podem receber parâmetros
🔹 Triggers são gatilhos disparados automaticamente por eventos
🔹 NEW e OLD permitem acessar registros em operações com triggers
🔹 Essas estruturas ajudam a automatizar regras e manter a consistência dos dados

  • Revise a diferença entre function, procedure e trigger.
  • Observe que functions retornam valores e podem ser usadas em expressões.
  • Pratique procedures com parâmetros IN, OUT e IN OUT.
  • Analise quando uma trigger deve ser BEFORE ou AFTER.
  • Estude o uso dos registros NEW e OLD em operações de inserção e exclusão.
  • Execute os exemplos no MySQL para observar o comportamento automático das triggers.

🧩 Atividade da semana

Desenvolva uma atividade prática envolvendo rotinas armazenadas e gatilhos. Crie uma function para realizar um cálculo, uma procedure para consultar ou manipular dados e triggers para automatizar alterações no banco.

✅ Orientações da atividade:

🔹 Criar uma function que retorne um valor calculado
🔹 Criar uma stored procedure com parâmetro de entrada
🔹 Criar uma trigger AFTER INSERT para atualizar automaticamente uma tabela
🔹 Criar uma trigger AFTER DELETE para devolver ou registrar informações
🔹 Criar uma tabela de LOG para registrar operações de INSERT, UPDATE e DELETE
🔹 Testar os comandos e verificar os resultados com SELECT

🎯 Encerramento

Functions, procedures e triggers são recursos importantes para tornar o banco de dados mais inteligente, organizado e automatizado. Com eles, é possível reaproveitar comandos, aplicar regras de negócio, atualizar informações automaticamente e registrar operações importantes para auditoria.
