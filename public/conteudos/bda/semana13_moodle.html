🚀 Consultas SQL Avançadas

Nesta semana iremos aprofundar os estudos sobre consultas SQL utilizando apelidos de tabelas e colunas, classificação de resultados, eliminação de duplicatas e operadores avançados.

Em consultas envolvendo múltiplas tabelas, é comum existirem atributos com o mesmo nome. Para evitar ambiguidades, utilizamos apelidos (alias). 

SELECT f.nome, d.nome
FROM funcionario AS f, departamento AS d
WHERE f.dnumero = d.dnumero;
💡 Os apelidos tornam as consultas mais legíveis e evitam ambiguidades.

Também estudaremos como eliminar linhas duplicadas utilizando DISTINCT. 

SELECT DISTINCT salario
FROM funcionario;

Além disso, veremos operadores importantes para filtragem avançada: LIKE, BETWEEN, IN, IS NULL e operadores lógicos. 

SELECT *
FROM funcionario
WHERE salario BETWEEN 30000 AND 50000;
✅ Consultas SQL avançadas ajudam a recuperar informações com maior precisão e organização.

🧠 Como estudar nesta semana

O objetivo desta semana é compreender técnicas avançadas de consultas SQL, utilizando apelidos, filtros e operadores para tornar as consultas mais claras, eficientes e organizadas.

📘 1º Passo – Leia o material da semana

Durante a leitura, observe:

✔ Como resolver ambiguidades em consultas
✔ Como utilizar apelidos em tabelas
✔ Como eliminar duplicatas com DISTINCT
✔ Como ordenar resultados com ORDER BY
🔍 2º Passo – Analise os exemplos SQL

Observe atentamente as cláusulas SELECT, FROM, WHERE e ORDER BY.

Perceba como pequenas mudanças alteram completamente o resultado da consulta.

📊 3º Passo – Pratique operadores avançados

Experimente criar consultas usando:

✔ LIKE para buscas por padrão
✔ BETWEEN para intervalos
✔ IN para múltiplos valores
✔ IS NULL para valores nulos
💻 4º Passo – Teste ORDER BY

Execute consultas ordenando resultados em ordem crescente e decrescente. 

SELECT pnome, salario
FROM funcionario
ORDER BY salario DESC;
🧩 5º Passo – Compare consultas

Compare resultados com e sem DISTINCT, ou com diferentes operadores lógicos.

Isso ajuda a entender como o SQL manipula conjuntos de dados.

💡 Dica: consultas bem organizadas facilitam manutenção, leitura e análise de dados.
