🚀 GROUP BY e HAVING

Nesta semana iremos estudar como utilizar funções agregadas, agrupamentos e filtros sobre grupos utilizando as cláusulas GROUP BY e HAVING.

O agrupamento permite dividir os registros em subconjuntos para aplicar funções como: COUNT, AVG, SUM, MAX e MIN. 

SELECT dnr, COUNT(*), AVG(salario)
FROM funcionario
GROUP BY dnr;
💡 O GROUP BY cria grupos de registros com base em um atributo em comum.

Também veremos como utilizar a cláusula HAVING para filtrar grupos após a agregação. 

SELECT cpf_supervisor, COUNT(*)
FROM funcionario
GROUP BY cpf_supervisor
HAVING COUNT(*) >= 2;
✅ Consultas agregadas ajudam a resumir e analisar grandes volumes de dados.

🧠 Como estudar nesta semana

O objetivo desta semana é compreender como o SQL agrupa registros e aplica funções agregadas para gerar análises resumidas dos dados.

📘 1º Passo – Estude as funções agregadas
✔ COUNT para contagem
✔ AVG para média
✔ SUM para soma
✔ MAX e MIN para extremos
🔍 2º Passo – Analise o GROUP BY

Observe como os registros são separados em grupos antes do cálculo das funções agregadas.

📊 3º Passo – Pratique agrupamentos

Execute consultas agrupando funcionários por departamento ou supervisor. 

SELECT dnr, AVG(salario)
FROM funcionario
GROUP BY dnr;
💻 4º Passo – Estude o HAVING

Utilize HAVING para filtrar grupos após o agrupamento. 

SELECT cpf_supervisor, COUNT(*)
FROM funcionario
GROUP BY cpf_supervisor
HAVING COUNT(*) >= 2;
🧩 5º Passo – Compare WHERE e HAVING

Entenda que WHERE filtra linhas antes do agrupamento e HAVING filtra grupos após a agregação.

💡 Dica: GROUP BY e HAVING são fundamentais para relatórios e análises em bancos de dados.
