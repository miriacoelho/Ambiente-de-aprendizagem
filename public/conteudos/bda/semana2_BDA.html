🚀 Retomando os fundamentos de Banco de Dados

Vamos continuar a revisão dos principais conteúdos estudados em FBD.

Nesta semana consolidaremos a criação e a alteração de tabelas, as restrições que preservam a integridade dos dados e os comandos usados para inserir, atualizar e excluir registros. A proposta é relacionar cada comando SQL à estrutura e às regras do banco de dados.

ℹ️ Como navegar: Clique no título de cada card (🚀 📚 🧠 📝 🧩 🎯) para abrir o conteúdo.

📚 Conteúdo da Semana

📌 CREATE TABLE: tipos de dados, definição de colunas e chave primária.
📌 ALTER TABLE: inclusão e modificação da estrutura de uma tabela.
📌 Restrições de integridade: PRIMARY KEY, FOREIGN KEY, NOT NULL e UNIQUE.
📌 INSERT: inclusão de registros respeitando a estrutura e as restrições.
📌 UPDATE: alteração segura dos dados com condições no WHERE.
📌 DELETE: exclusão de registros e efeitos da integridade referencial.

🧠 Como estudar nesta semana

  1. Abra os scripts da revisão e identifique os comandos DDL e DML.
  2. Execute o CREATE TABLE e confira tipos, chaves e restrições.
  3. Use ALTER TABLE para modificar a estrutura criada.
  4. Teste INSERT, UPDATE e DELETE observando o uso correto do WHERE.
  5. Analise as mensagens do SGBD quando uma restrição de integridade é violada.

📝 Materiais da semana

Revisão de FBD
Material sobre SQL DDL, DML e restrições de integridade.
Scripts da revisão
Comandos CREATE, ALTER, INSERT, UPDATE e DELETE.

🧩 Atividade da semana

Execute os comandos no MySQL, confira a estrutura após CREATE e ALTER, valide as restrições e verifique cuidadosamente as condições utilizadas no UPDATE e no DELETE.

Exercício de revisãoMaterial do exercício
Dica: antes de UPDATE ou DELETE, faça um SELECT com a mesma condição WHERE.

🎯 Encerramento

Ao concluir esta revisão, você deverá reconhecer a finalidade dos comandos DDL e DML, criar e alterar tabelas, manipular registros com segurança e explicar como as restrições de integridade protegem a consistência do banco de dados. Esses fundamentos serão a base para avançarmos à Álgebra Relacional.
