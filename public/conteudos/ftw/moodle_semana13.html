🚀 Trabalhando com Frames no HTML

Nesta aula você aprenderá como dividir a tela do navegador em múltiplas áreas independentes utilizando Frames e também como incorporar páginas externas com IFrames.

💡 Apesar de não serem mais recomendados no HTML5, entender Frames é fundamental para compreender a evolução do HTML.

🧠 Como estudar nesta semana

O aprendizado de Frames acontece na prática. Você precisa criar os arquivos e visualizar como a tela do navegador é dividida em áreas independentes.

  1. Crie 3 páginas HTML simples: topo.html, menu.html e conteudo.html
  2. Crie um arquivo principal chamado index.html utilizando a tag <frameset>
  3. Divida a tela utilizando os atributos rows e cols
  4. Configure os atributos border, frameborder e framespacing
  5. Associe cada página criada a um <frame>
  6. Teste diferentes proporções (%, px) para entender a divisão da tela
🧪 Prática recomendada:
Monte um layout com:
  • Topo ocupando 20% da tela
  • Menu lateral ocupando 30%
  • Área de conteúdo ocupando 70%
💡 Dica: Altere os valores de rows e cols e atualize o navegador para visualizar como o layout se reorganiza.
🎯 Desafio: Criar uma divisão combinando linhas e colunas no mesmo <frameset>.
