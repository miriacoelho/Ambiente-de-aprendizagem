🚀 Formulários HTML e Coleta de Dados

Nesta aula estudaremos os formulários HTML, elementos fundamentais para a interação entre usuários e aplicações web. Aprenderemos a criar campos de entrada, listas de seleção, botões e mecanismos para envio de informações.

💡 Você vai aprender:
🔹 Como utilizar a tag <form>
🔹 Diferenças entre GET e POST
🔹 Tipos de campos <input>
🔹 Uso de textarea, select e button
🔹 Organização com fieldset e legend
