🌐 Links Externos: Conectando a Web

Os links externos permitem navegar entre diferentes páginas e sites na internet, sendo fundamentais para a construção da web.

💡 Pense assim: links externos funcionam como “pontes” entre diferentes sites.

ℹ️ Como navegar: Clique no título de cada card (🌐🎥 📚 🧠 📝 🔗🧩 🎯) para abrir o conteúdo da semana.

📚 Conteúdo da Semana
📌 O que são links externos
📌 Navegação entre páginas da internet
📌 Uso da tag <a> com href absoluto
📌 Protocolo mailto (envio de e-mails)
📌 Atributo target (_blank, _self, etc.)
📌 Conexão com arquivos externos
📌 Links para documentos, imagens e mídias
📌 Introdução à tag <link>
💡 Objetivo: Criar links que conectam páginas e recursos externos de forma eficiente.

🧠 Como estudar nesta semana
  1. Crie uma página HTML
  2. Adicione links para sites externos
  3. Use target="_blank"
  4. Teste os links no navegador
  5. Experimente o mailto
  6. Crie links para arquivos (PDF, imagens)
🧪 Prática: Crie um site com links para Google, YouTube e um e-mail.
💡 Dica: sempre teste se o link abre corretamente.
🎯 Desafio: crie um link que abra em nova aba e outro na mesma aba.
