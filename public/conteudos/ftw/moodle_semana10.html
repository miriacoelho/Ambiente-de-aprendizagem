🚀 Links Internos: Navegação dentro da página

Os links internos permitem a navegação dentro de um mesmo documento HTML, levando o usuário diretamente para seções específicas da página.

💡 Pense assim: links internos funcionam como um “índice clicável” dentro da própria página.

🧠 Como estudar nesta semana

Aprenda praticando! O domínio de links internos acontece quando você cria páginas reais e testa a navegação.

  1. Crie uma página HTML simples
  2. Adicione um menu com 3 links internos
  3. Crie seções utilizando o atributo id
  4. Conecte os links usando href="#id"
  5. Teste a navegação no navegador
  6. Adicione mais conteúdo para simular uma página longa
  7. Organize melhor o layout com títulos e espaçamento
🧪 Prática recomendada:
Crie um mini site com:
  • Menu no topo
  • Seções: Início, Sobre e Contato
  • Navegação funcional entre elas
💡 Dica: Sempre atualize a página após cada alteração e clique nos links para verificar se estão funcionando corretamente.
🎯 Desafio: Adicione um botão "Voltar ao topo" usando links internos.
