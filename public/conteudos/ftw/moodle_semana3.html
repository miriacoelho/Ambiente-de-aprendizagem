🚀 HTML para formatação de textos

Nesta aula vamos aprofundar a formatação de textos em HTML.

Estudaremos as principais tags de formatação como <b> vs <strong>, <i> vs <em>, <u> vs <ins>, além de tags semânticas, entidades HTML, cabeçalhos (h1–h6), uso de cores e boas práticas de acessibilidade.

🎯 Objetivo: compreender a diferença entre formatação visual e semântica e aplicar boas práticas modernas em HTML5.

🧠 Como estudar nesta semana

Nesta semana vamos aprender a utilizar tags HTML para formatação de texto, compreender a diferença entre tags semânticas e não semânticas e aplicar cores e entidades HTML.
A melhor forma de aprender HTML é praticando e testando cada elemento.

📘 1º Passo – Analise os exemplos do material

Leia atentamente os exemplos comparativos entre:

  • Tags semânticas (header, section, article, footer)
  • Tags não semânticas (div e span)

Observe como as tags semânticas ajudam a dar significado e organização ao conteúdo da página.

💻 2º Passo – Teste as tags no seu editor HTML

Crie um arquivo index.html e experimente inserir algumas tags.

<h1>Título da Página</h1>
<p>Este é um <strong>texto em destaque</strong>.</p>
<p>Este é um <em>texto em ênfase</em>.</p>
<p>Este é um <u>texto sublinhado</u>.</p>
🎨 3º Passo – Experimente aplicar cores

Teste cores utilizando duas formas diferentes:

  • Cores nominais → red, blue, green
  • Cores hexadecimais → #FF0000, #1E3A8A
<p><font color="red">Texto vermelho</font></p>
<p><font color="#1E3A8A">Texto azul escuro</font></p>
