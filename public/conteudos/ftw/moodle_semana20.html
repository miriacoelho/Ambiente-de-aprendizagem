🚀 Guia de Revisão para a Avaliação de HTML

Nesta revisão, vamos retomar os principais recursos da linguagem HTML estudados durante o semestre. O objetivo é reforçar a prática de criação de páginas e websites utilizando estrutura, formatação, mídias, links, frames, tabelas e formulários.

💡 Conteúdos da prova:
🔹 Formatar fontes, textos e cores com HTML
🔹 Criar réguas horizontais e listas em HTML
🔹 Inserir imagens e vídeos em páginas HTML
🔹 Criar links internos e externos
🔹 Organizar a criação de websites com várias páginas
🔹 Utilizar frames e framesets
🔹 Construir tabelas com linhas, colunas e mesclagens
🔹 Criar formulários com campos, botões e seleção de dados

🧠 Como estudar nesta semana
  • Revise os exemplos feitos em aula e identifique a função de cada tag HTML.
  • Pratique a criação de páginas com títulos, parágrafos, quebras de linha, cores e formatação de texto.
  • Crie réguas horizontais, listas ordenadas, listas não ordenadas e listas aninhadas.
  • Insira imagens usando src, alt, width e height.
  • Insira vídeos com controles de reprodução.
  • Crie links externos para sites da internet e links internos entre páginas do próprio site.
  • Monte um pequeno website com página inicial, menu, páginas internas e organização de arquivos.
  • Treine frames e framesets, usando target para abrir páginas em áreas específicas.
  • Construa tabelas com cabeçalho, linhas, células, colspan e rowspan.
  • Crie formulários com campos de texto, senha, e-mail, seleção, caixa de marcação, área de texto e botões.
💡 Pergunta guia: Você conseguiria criar um website completo, com páginas interligadas, mídias, tabela e formulário, utilizando apenas HTML?

🧩 Atividade da semana

Como preparação para a prova, desenvolva um pequeno website em HTML contendo os principais recursos estudados.

  • Formatação de fontes, textos e cores;
  • Régua horizontal e listas ordenadas, não ordenadas e aninhadas;
  • Pelo menos uma imagem e um vídeo;
  • Links internos e externos;
  • Mais de uma página HTML interligada;
  • Uso de frames ou frameset;
  • Uma tabela com cabeçalho, linhas, colunas, colspan e rowspan;
  • Um formulário contendo campos de texto, e-mail, senha, seleção, área de texto e botões.

🎯 Encerramento

A prova avaliará sua capacidade de criar páginas HTML utilizando os principais elementos estudados durante o semestre. Revise a função de cada tag, pratique a construção de páginas completas e observe como os elementos se conectam dentro de um website. Dê atenção especial à estrutura do código, aos links entre páginas, às tabelas, aos frames e aos formulários, pois esses recursos demonstram domínio prático da linguagem HTML.
